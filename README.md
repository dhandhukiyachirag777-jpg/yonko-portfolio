## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)

### Run Locally
```bash
# Clone the repository
git clone https://github.com/dhandhukiyachirag777-jpg/yonko-portfolio.git

# Navigate into directory
cd yonko-portfolio

# Start local server
npm start
```

Open your browser at `http://localhost:5000` to view the live portfolio.
